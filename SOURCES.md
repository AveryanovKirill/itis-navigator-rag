# Документы и внешние компоненты

В публичную поставку входят исходный код и тесты. Полные тексты официальных страниц,
PDF, расписание, их фрагменты, векторы и экспериментальные ответы не включены.
Публичная доступность страницы сама по себе не означает разрешения разместить её
полную копию в другом репозитории. Явная лицензия на распространение выбранных
материалов ИТИС при подготовке не установлена; условия других подразделений КФУ
не распространяются автоматически на эти страницы.

MIT в LICENSE относится к собственному коду проекта и авторским тестовым фикстурам.
Она не перелицензирует документы КФУ, модели, сторонний MCP-Demo или Python-пакеты.

## Как получить корпус локально

1. Убедитесь, что имеете право использовать выбранные тексты и соблюдаете условия источника.
2. Выполните `python -m src.bootstrap --fetch-official` при пустой папке `docs/`.
   Импортёр читает только HTTPS источники КФУ, не обходит авторизацию и не выдумывает
   недоступные данные. При ошибке существующие `docs/` не заменяются.
3. Либо самостоятельно сохраните разрешённые UTF-8 `.txt`/`.md` в `docs/` и укажите
   URL, время получения и ограничения в `data/sources.json` по `data/sources.example.json`.
   Нужен именно извлечённый текст, а не HTML с расширением .txt; PDF сначала нужно
   преобразовать в текст. Страницы, на которые есть лишь ссылка, не считаются прочитанными.
4. Выполните `python -m src.bootstrap`. Готовый совместимый индекс проверяется без
   перестроения. Для намеренного обновления вашей копии есть `--rebuild-index`.

Импортируемые адреса:

- https://kpfu.ru/itis
- https://kpfu.ru/itis/obuchenie-v-itis/stipendialnye-programmy
- https://kpfu.ru/itis/zaselenie-v-obschezhitiya-itis
- https://kpfu.ru/itis/obuchenie-v-itis/praktika
- https://kpfu.ru/portal/docs/F_626640358/Reg..tek..kontrolya.s.DOT.pdf

Копии и SHA256 загруженных ресурсов остаются только на компьютере пользователя.
Дата получения не доказывает актуальность каждой нормы. Регламент ДОТ 2020 года
не следует автоматически применять ко всем очным экзаменам; отсутствие отмены
регламента импортёр не устанавливает. Нормативные ответы требуют проверки источника.

В `.env.example` указан стартовый порог сходства 0.817020058631897 из прежней
конфигурации. На новых снимках и собственных документах качество этого порога не
измерено. Проверяйте известные и отсутствующие ответы, используйте `search --raw`
для диагностики. При наличии собственного `eval/calibration.json` можно выполнить
`python -m src.cli calibrate`, затем очистить THRESHOLD в `.env` для использования
полученной калибровки. Эталоны не включаются в запрос к LLM.

## Расписание

Это необязательный инструмент `get_group_schedule`, отдельный от `search_docs`.
Для него нужны Git, Node.js >=22.13 и npm; настройка — `scripts/setup_schedule.ps1`.
Скрипт клонирует https://github.com/GreenSLA/MCP-Demo на зафиксированный commit
`b45fbf29884eb6b5e88225440dc36110546c5958` и устанавливает зависимости в `reference/`.
Код этого репозитория не распространяется в данной поставке; перед использованием
учтите его собственные условия. Наличие разрешающей лицензии не предполагается.

MCP-Demo читает публичную Google-таблицу. Текущая официальная страница расписания:
https://kpfu.ru/itis/obuchenie-v-itis . Полная официальная атрибуция Google-таблицы
не установлена. Новая установка не содержит прежнего снимка и файла его визуальной
сверки; не выдавайте автоматически таблицу за проверенное официальное расписание.
Сохраняйте `mode`, `fetchedAt` и ограничения ответа. Отмены, подгруппы и чётность
недели для произвольного «завтра» автоматически не подтверждаются.
Отсутствие Node, внешнего проекта или сети не мешает обычному поиску документов.

## Модели и библиотеки

- Qwen3:4b скачивается отдельно командой `ollama pull qwen3:4b`.
  Карточка: https://ollama.com/library/qwen3:4b . Веса не распространяются с проектом.
- Эмбеддинги: https://huggingface.co/intfloat/multilingual-e5-small .
  Для воспроизводимости задан revision в `.env.example`; веса загружаются отдельно.
- Зависимости Python перечислены в requirements-lock.txt и сохраняют собственные лицензии.
- Учебные фикстуры в tests/fixtures/demo/ являются вымышленными, явно помечены
  и не копируются в основной корпус автоматически.
